# planner

The **adaptive daily study-plan engine** behind the "What should I study today?"
decision.

It is the brain of the Mentor Kit family:

- Takes **deadlines**, **syllabus status**, **progress**, **mastery**, **errors**,
  **revision needs**, **difficulty** and **time budget**.
- Computes the next best study action.
- Produces a concrete **TODAY** plan (subject, exact topic, exact task, depth,
  questions, stopping point, revision, carry-forward).

## Status

Early engine — the decision logic now lives in the AI mentor layer
(see `mentor-kit`). This repo will hold the standalone planning engine code.
